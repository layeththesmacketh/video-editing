# taste-research

Pre-production research, not editing.

## Input

- **Talent name** (for a dossier) or **brand / campaign reference** (for a reference reel).
- Optional: brief, prior cuts, prior interviews.

## Output

### Talent dossier

```json
{
  "name": "...",
  "voice": "how they talk — cadence, vocabulary, what they avoid",
  "physical": "how they move on camera — stillness vs. kinetic, hands, eyes",
  "stakes": "what they care about right now (current project, public moment)",
  "landmines": "topics that derail them or push them into PR mode",
  "openings": "promising angles a thoughtful interviewer would pursue",
  "references": ["URL or title", "..."]
}
```

### Reference reel

A short ordered list of reference cuts (3–8) with one-line notes on what we're stealing from each.

## How to research

- Use `WebSearch` / `WebFetch` to find recent interviews, profiles, and on-camera appearances.
- Note delivery, not just content. The dossier is about how they show up, not their bio.
- For brand/campaign work, look at the last 2 years of the brand's brand-film output. Note pacing, music posture, B-roll density.

## When NOT to use

- Mid-edit. If you're already in a paper edit, you should have done this first.
- For routine clients (recurring IM8, NYFW). The dossier is for unfamiliar talent or new brand voices.
